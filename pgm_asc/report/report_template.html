PGM Adaptive Self-Consistency

추론 응답을 하나씩 샘플링하면서, 의미적으로 비슷한 응답을 묶는 여러 partition 위의 확률 모델(PGM)로 정답 분포를 추정하고, 확신이 충분하면 생성을 멈춥니다. 이 페이지는 모델 구조, 실험 설정, 결과를 한곳에 정리했습니다.

01

PGM 구조

언어모델은 고정합니다. 질문 \(q\)에 대해 응답 \(y_1, y_2, \dots\)를 하나씩 받으면서, 매 시점 \(t\)에 지금까지 나온 후보 답 집합 \(\mathcal{A}_t\)와 "아직 안 나온 답" \(\texttt{OTHER}\) 위의 분포 \(p_t(a \mid y_{1:t})\)를 계산하고, 이 분포가 충분히 한쪽으로 쏠리면 생성을 멈춥니다. 학습하는 것은 이 분포를 만드는 작은 head 네 개뿐입니다.

1. 전체 구조

점선 상자는 고정된 언어모델 쪽, 파란 상자는 학습되는 부분(\(f_{\text{sup}}, \alpha, f_{\text{gate}}, f_{\text{oth}}\)과 보정 온도 \(T\))입니다. 응답이 하나 늘 때마다 오른쪽 끝까지 다시 계산합니다.

2. 응답 단위 입력

응답 \(y_j\)마다 세 가지를 얻습니다. 모두 \(y_1,\dots,y_t\)만 보고 계산하며 미래 응답이나 정답은 쓰지 않습니다.

(1) \[ a_j = \operatorname{extract}(y_j), \qquad x_j \in \mathbb{R}^{9}, \qquad e_j = \frac{\bar h_j}{\lVert \bar h_j \rVert}, \quad \bar h_j = \frac{1}{\lvert R_j \rvert} \sum_{i \in R_j} h^{(L)}_{j,i} \]
\(a_j\): 추출한 최종 답. 동치인 답끼리 하나의 후보 \(a \in \mathcal{A}_t\)로 묶습니다. \(x_j\): teacher-forcing pass에서 얻은 확신도 feature 9개(추론·답 부분 평균 log-prob, 평균 entropy, 세 가지 길이의 log, truncation 및 빈 구간 표시). \(e_j\): 마지막 layer hidden state \(h^{(L)}\)를 추론 구간 토큰 \(R_j\)에 대해 평균하고 단위화한 embedding.

3. Partition: 비슷한 추론끼리 묶기

Embedding \(e_j\)를 들어오는 순서대로 online clustering합니다. 기존 cluster 중심 \(\mu_k\) 중 가장 가까운 것과의 cosine이 threshold \(\tau_m\) 이상이면 합류하고, 아니면 새 cluster를 엽니다. Threshold를 바꿔 같은 응답 묶음에 대해 거친 것부터 잘게 나눈 것까지 6개 partition \(\mathcal{P}_0,\dots,\mathcal{P}_5\)를 동시에 유지합니다. 답이 같아도 다른 cluster일 수 있고, 답이 달라도 같은 cluster일 수 있습니다.

(2) \[ k^\star = \arg\max_k \cos(e_j, \mu_k), \qquad C_m(j) = \begin{cases} k^\star & \cos(e_j, \mu_{k^\star}) \ge \tau_m \\ \text{new cluster} & \text{otherwise} \end{cases} \] \[ \mathcal{P}_0 = \text{all-one}, \quad \tau_{1..4} = Q_{0.1},\, Q_{0.4},\, Q_{0.7},\, Q_{0.9} \text{ of train pairwise } \cos, \quad \mathcal{P}_5 = \text{singletons} \]
\(\lvert C_m(j) \rvert\): partition \(m\)에서 응답 \(j\)가 속한 cluster의 크기. 서로 같은 묶음이 된 partition은 하나만 남깁니다(중복 partition mask).

4. Partition별 후보 분포

응답 하나가 자기 답에 주는 표 \(s_j\)를 확신도로 정하고, 같은 cluster에 몰린 응답은 서로 중복된 증거로 보고 cluster 크기만큼 할인합니다.

(3) \[ s_j = \operatorname{softplus}\!\big(f_{\text{sup}}(x_j)\big) > 0 \] (4) \[ \ell_m(a) = \sum_{j \le t \,:\, a_j = a} \lvert C_m(j) \rvert^{\,\alpha - 1}\, s_j, \qquad \ell(\texttt{OTHER}) = f_{\text{oth}}(w_t), \qquad \alpha = \sigma(\beta) \in (0,1) \] (5) \[ p_m(a) = \frac{\exp \ell_m(a)}{\sum_{b \in \mathcal{A}_t \cup \{\texttt{OTHER}\}} \exp \ell_m(b)} \]
\(w_t \in \mathbb{R}^{25}\): prefix 수준 feature(득표 분포 8개, 전체·선두 후보의 확신도 통계 17개). 학습된 \(\alpha\)는 약 0.43–0.48입니다.
경우식 (4)가 되는 것의미
\(\mathcal{P}_5\) singletons, 또는 \(\alpha = 1\)\(\ell(a) = \sum_{a_j = a} s_j\)확신도 가중 다수결. partition이 아무 역할을 하지 않음
\(\mathcal{P}_0\) all-one\(\ell(a) = t^{\alpha-1} \sum_{a_j = a} s_j\)가중 다수결 전체를 \(t^{\alpha-1}\)로 눌러서 OTHER 대비 확신을 낮춤
cosine partition, \(\alpha \to 0\)\(\ell(a) \approx \sum_{C} \frac{1}{\lvert C\rvert}\sum_{j \in C, a_j = a} s_j\)cluster 하나가 대략 한 표. 비슷한 추론을 반복한 응답은 한 번만 셈

5. Mixture, 보정, 정지

(6) \[ \pi_m = \frac{\exp f_{\text{gate}}(g_m)}{\sum_{m'} \exp f_{\text{gate}}(g_{m'})}, \qquad p_t(a) = \sum_{m=0}^{5} \pi_m\, p_m(a) \] (7) \[ \tilde p_t(a) \propto p_t(a)^{1/T}, \qquad \hat a_t = \arg\max_{a \in \mathcal{A}_t} \tilde p_t(a) \] (8) \[ \text{stop at } t \iff t \ge 2 \;\wedge\; \tilde p_t(\hat a_t) \ge \gamma \;\wedge\; \tilde p_t(\hat a_t) > \tilde p_t(\texttt{OTHER}), \qquad t \le 16 \]
\(g_m \in \mathbb{R}^{12}\): partition \(m\)의 구조 feature(cluster 수 비율, cluster 크기 entropy, singleton 비율, 최대 cluster 비율, cluster 내부·사이 cosine 평균과 표준편차 등). \(T\)는 calibration 128문항에서 맞춘 전역 온도. 멈추면 \(\hat a_t\)를 최종 답으로 냅니다.

6. 학습 목표

(9) \[ \mathcal{L} = \frac{1}{\lvert Q \rvert} \sum_{q \in Q} \sum_{t=1}^{16} \lambda_t \big[-\log p_t(a^\star_t)\big], \qquad a^\star_t = \begin{cases} \text{gold와 동치인 후보} & \text{있으면} \\ \texttt{OTHER} & \text{없으면} \end{cases} \] \[ \lambda_t = 0.2\ (t \le 2), \quad 0.1\ (t \le 4), \quad 0.05\ (t \le 8), \quad 0.025\ (t \le 16) \]
구간 1–2, 3–4, 5–8, 9–16이 각각 같은 총 가중치 0.4를 받아, 응답이 적은 초반 prefix도 후반만큼 중요하게 학습합니다. 16개 응답 bank를 미리 만들어 두었으므로 모든 prefix를 한 번에 학습합니다.

7. 예시: 응답 6개에서 분포 만들기

응답 6개의 답이 12, 12, 15, 12, 8, 15라고 합시다. 확신도는 모두 \(s_j = 1\), \(\ell(\texttt{OTHER}) = 0.5\), gate는 \(\pi = (0.15, 0.55, 0.30)\)으로 두었습니다(설명용 값). 응답 1·2는 거의 같은 추론이고, 3·6도 서로 비슷합니다. \(\alpha\)를 움직이면 cluster 할인이 어떻게 분포를 바꾸는지 보입니다.

0.45 학습값 ≈ 0.45 · \(\alpha = 1\)이면 세 partition이 모두 같은 다수결이 됩니다
각 행에서 둥근 상자가 cluster입니다. 오른쪽 막대가 그 partition의 \(p_m\)이고, 마지막 행이 식 (6)의 mixture입니다.

8. 운영점 (threshold \(\gamma\))

  • selected: \(\gamma \in \{0.5, 0.6, \dots, 0.995, \text{없음}\}\) 중 dev 정확도 \(\ge\) dev SC16 − 1 pp를 만족하면서 토큰이 가장 적은 값. 본문 표의 기본 운영점입니다.
  • fixed95: \(\gamma = 0.95\)로 고정. dev 선택의 영향을 빼고 비교하기 위한 보조 운영점입니다.

Test 데이터는 threshold 선택에 쓰지 않으며, 학습·선택이 끝난 정책은 sha256 lock으로 고정한 뒤 평가합니다.

05

해석과 한계

  • 효율은 있지만 PGM 고유의 효과는 아니다. MATH·GSM8K에서 mixture는 SC16 정확도를 거의 유지하며 토큰을 크게 줄이지만, dev-tuned ASC가 비슷한 지점에 도달합니다. Llama-3.1-8B MATH500(60.8 % / 4,062 vs SC16 58.8 % / 7,709)이 가장 뚜렷한 개선 사례입니다.
  • Partition 구조의 근거가 약하다. 64개 구조 대조 중 Holm 유의는 1개(Llama GSM8K vs candidate_confidence, +0.99 pp, 대신 토큰 12 % 더 사용). Size-matched random grouping과는 어느 셀에서도 차이가 없습니다. 학습된 α(≈ 0.45)가 독립 투표보다 dev NLL을 2–3 % 개선하지만, 무작위로 같은 크기의 cluster를 만들어도 같은 이득이 납니다. 즉 이득은 "cluster 크기 분포"에서 오고 "어떤 응답끼리 묶였는가"(의미)에서 오지 않습니다.
  • Hidden-state embedding의 기여도 작다. deepsets_embedding은 deepsets_confidence 대비 정확도 차이가 거의 없고 토큰은 약 1.12배입니다.
  • Omni-MATH에서는 보수적이다. In-domain head는 정확도를 지키지만 절감이 6–19 %에 그칩니다. MATH에서 학습한 head를 옮기면 4개 중 3개 모델에서 더 일찍 멈춰 더 많이 아끼되 정확도를 최대 0.7 pp 잃습니다(Qwen2.5-3B는 예외).

주의할 점

  • 출력 토큰 수는 입력 처리와 teacher-forcing feature pass를 빼고 셉니다. 실제 서빙 지연 시간 측정이 아닙니다.
  • Holm 보정은 셀마다 4개 주요 대조만 덮습니다. 전체 실험 행렬에 대한 유의성 주장은 하지 않습니다.
  • 판정기는 공개된 xVerify-3B-Ia입니다. 원 ReASC의 판정 모델 별칭을 쓸 수 없어 통제된 재현이며, 과거 벤치마크 점수와 같다고 주장하지 않습니다.
  • Omni-MATH와 Llama 셀은 원래 protocol 이후에 추가했습니다. Llama Omni 생성은 vLLM 0.11의 preemption assertion 때문에 GPU 메모리 비율 0.5로 돌렸고, 샘플링과 seed는 같습니다.
