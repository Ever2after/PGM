PGM v2: 오답이 뭉치는 방식과 예측분포로 언제 멈출지 정하기

v1의 학습형 partition mixture를 버리고, 파라미터 4개짜리 생성형 그래프 모델에서 다시 시작했습니다. 모델은 "응답을 하나 더 받으면 정답을 맞힐 확률이 얼마나 오를까"를 직접 계산해 생성을 멈추고, 답은 다수결로 냅니다. 구조를 하나씩 빼고 더하는 ablation으로 어떤 노드가 실제로 필요한지 확인했습니다.

00

요약

정확도는 xVerify-3B-Ia 판정, 토큰은 응답 본문과 두 번의 정답 추출 출력을 합친 질문당 평균 출력 토큰(v1과 같은 정의)입니다. 그래프와 표의 토큰은 같은 셀 SC16 대비 비율로 표시합니다. 숫자는 이 페이지를 만든 결과 파일에서 직접 계산됩니다.

01

모델과 수식

v1에서 검증된 것만 남겼습니다. 응답 확신도는 대부분 문제 난이도를 반영하고(같은 질문 안 AUC 0.53–0.69), 오답이 뭉치는 정도는 난이도에 따라 다르며, 어려운 문제에서 토큰 대부분이 16개 cap까지 가는 질문에 쓰입니다. 그래서 질문 난이도 \(q\)를 잠재변수로 두고, 오답이 뭉치는 방식을 명시적으로 모델링한 뒤, 모델의 예측분포로 "더 받을 가치"를 계산합니다.

1. 그래프 구조

원은 확률변수, 사각형은 결정적 함수, 파란 원은 관측값, 점선은 ablation으로 시험했지만 이득이 없어 최종 모델(M1)에서 뺀 노드입니다. 판(plate) 안의 노드는 응답마다 반복됩니다.

2. 생성 과정

(1) \[ q \sim \mathrm{Beta}(a, b), \qquad z_j \mid q \sim \mathrm{Bernoulli}(q), \qquad j = 1, \dots, 16 \] (2) \[ a_j \mid z_j, c, a_{(3) \[ \log \theta(q) = t_0 + t_1 (2q - 1) \]
\(c\): 정답(값 자체는 연속 base measure \(H\)에서 나온다고 보며, \(H\)는 모든 가설에 같은 인수로 들어가 사후확률에서 약분됩니다). \(n^{-}_w\): 이전 응답 중 오답 \(w\)를 낸 수, \(m_j\): 이전 오답 응답 수. 식 (2)의 오답 부분은 Chinese restaurant process(CRP)이며 \(\theta\)가 작을수록 오답이 한두 개로 몰립니다. 빈 답(추출 실패)은 \(z_j = 0\)인 응답으로만 셉니다. 파라미터는 \(a, b, t_0, t_1\) 4개입니다.

3. 정확한 사후확률

시점 \(t\)까지 관측한 답 \(D_t = a_{1:t}\)에서 후보 \(a\)의 득표를 \(n_a\), 나머지 득표를 \(n_k\)라 하면, "\(a\)가 정답"이라는 가설의 우도는 정답 부분과 오답 CRP(Ewens 분포) 부분의 곱이 됩니다.

(4) \[ p(D_t \mid c = a, q) \;\propto\; q^{\,n_a} (1-q)^{\,t - n_a} \cdot \theta(q)^{K_{-a}} \prod_{k \ne a} \Gamma(n_k) \cdot \frac{\Gamma(\theta(q))}{\Gamma(\theta(q) + t - n_a)} \] (5) \[ P(c = a \mid D_t) = \frac{\int_0^1 p(q)\, p(D_t \mid c = a, q)\, dq}{\sum_{a' \in \mathcal{A}_t \cup \{\texttt{OTHER}\}} \int_0^1 p(q)\, p(D_t \mid c = a', q)\, dq} \]
\(K_{-a}\): \(a\)를 뺀 서로 다른 오답의 수. \(\texttt{OTHER}\)는 "정답이 아직 안 나왔다"는 가설로 \(n_{\texttt{OTHER}} = 0\)입니다. 적분은 \(q = \sigma(z)\), \(z \in [-7, 7]\)의 80칸 grid에서 계산합니다. 근사 없이 닫힌 형태입니다.

4. 답과 정지 규칙

(6) \[ \hat a_t = \arg\max_{a \in \mathcal{A}_t:\; n_a = \max_{b} n_b} P(c = a \mid D_t), \qquad A_t = P(c = \hat a_t \mid D_t) \] (7) \[ \mathrm{VOI}_t = \max_{h \in \{1, 2, 4, 8, 16 - t\}} \frac{\mathbb{E}\big[A_{t+h} \mid D_t\big] - A_t}{h}, \qquad \text{stop at } t \iff t \ge 2 \;\wedge\; \mathrm{VOI}_t < \lambda \]
답은 다수결이고, 동률은 사후확률로 깹니다. \(A_t\)는 지금 멈추면 맞힐 확률입니다. \(\mathbb{E}[A_{t+h} \mid D_t]\)는 사후분포에서 \((c, q)\)를 48번 뽑고, 식 (1)–(3)으로 응답 \(h\)개를 더 생성한 뒤 식 (5)로 다시 계산한 \(A_{t+h}\)의 평균입니다. 즉 "응답 하나당 기대 정확도 상승"이 \(\lambda\)보다 작으면 멈춥니다. 쉬운 문제(이미 확실)와 너무 어려운 문제(더 받아도 소용없음)가 모두 일찍 멈춥니다. ASC·ESC·ReASC는 예측분포가 없어서 이 값을 계산할 수 없습니다.

5. 학습

(8) \[ \hat\phi = \arg\max_{\phi = (a, b, t_0, t_1)} \sum_{i \in \text{train}} \log \int_0^1 p_\phi(q)\, p_\phi\big(a_{i,1:16} \mid c = c^\star_i, q\big)\, dq \]
\(c^\star_i\): 16개 응답 중 정답으로 판정된 후보(없으면 \(\texttt{OTHER}\)). train 800문항, L-BFGS, 셀당 수 초. 신경망이나 hidden state는 쓰지 않습니다.

6. 시험한 확장 노드 (ablation, 최종 모델에서 제외)

(9) \[ x_j \mid q, z_j \sim \mathcal{N}\!\big(b_0 + b_1 \tfrac{\operatorname{logit} q}{7} + b_2 z_j,\; s^2\big) \qquad \text{(확신도 노드, M2)} \] (10) \[ a_j = a_{k^\star_j} \ \text{w.p. } r_j = \rho\, u_j^{\kappa}, \quad k^\star_j = \arg\max_{k\(x_j\): ReASC가 쓰는 bottom-10% self-certainty. \(\mathrm{sim}\): reasoning 텍스트의 단어 3-gram Jaccard, hidden state cosine, 또는 같은 질문 안에서 무작위로 섞은 통제군. 복사된 응답은 정답에 대한 증거가 되지 않으므로 중복된 추론을 할인합니다.

평가 지표

(11) \[ \mathrm{Frontier} = \frac{1}{|B|} \sum_{\beta \in B} \max_{\tau:\; T(\tau) \le \beta} \mathrm{Acc}(\tau), \qquad B = 60 \text{ budgets in } [T_{\mathrm{SC@2}}, T_{\mathrm{SC16}}] \] (12) \[ \tau^\star = \arg\min_{\tau} \big\{ T(\tau) : \mathrm{Acc}(\tau) \ge \mathrm{Acc}_{\mathrm{SC16}} - 1\,\mathrm{pp} \big\} \quad \text{(matched accuracy)} \]
\(\tau\): 방법의 threshold, \(T(\tau)\), \(\mathrm{Acc}(\tau)\): 그 threshold의 평균 토큰과 정확도. Frontier는 곡선이 "왼쪽 위"에 있을수록 커지는 요약값으로, 모든 방법에 똑같이 적용하는 oracle 요약입니다. 실제 운영점 (12)는 정답을 보지 않고 고릅니다. dev(200문항)에서 고르는 방식과, test를 무작위로 반씩 나눠 한쪽에서 고른 threshold를 다른 쪽에 적용하는 2-fold cross-fitting 두 가지를 보고합니다. 이 데이터에서는 dev가 test보다 훨씬 쉬워서(예: Llama MATH SC16 dev 86% vs test 59%) cross-fitting이 주 지표입니다. 차이는 질문 단위 paired bootstrap(10,000회) 95% CI와 exact McNemar p로 검정합니다.
03

토큰-정확도 곡선

각 방법의 threshold를 쓸어서 얻은 test 곡선입니다. 왼쪽 위에 있을수록 같은 토큰으로 더 정확합니다. x축은 SC16 대비 토큰(log), ◆는 cross-fitting으로 고른 운영점(정확도 ≥ SC16 − 1 pp 중 최소 토큰; test의 두 절반이 서로 다른 threshold를 쓰므로 곡선에서 약간 벗어날 수 있음), ○는 baseline 기본값입니다. 점에 마우스를 올리면 수치가 보입니다.

07

진단

1. 사후확률 argmax vs 다수결

처음 버전은 식 (6) 대신 사후확률이 가장 큰 답을 냈습니다. Omni-MATH에서는 이 답이 16개 시점에서 다수결과 26–58% 달랐고, 정확도가 SC16보다 낮았습니다(Gemma 28.2 vs 31.6, Llama 13.2 vs 17.2). 어려운 셋에서는 적합된 사전분포가 \(q \approx 0\) 쪽에 몰리고(Gemma Omni \(a \approx 0.02\)), 그러면 3표를 받은 답을 "우연히 뭉친 오답"으로 해석해 1표짜리 답을 선호합니다. 낮은 \(q\)에서 CRP가 오답 군집을 실제보다 강하게 예측하는 오설정입니다.

그래서 모델은 언제 멈출지만 정하고 답은 다수결로 내도록 바꿨습니다. VOI도 실제로 낼 답 기준으로 계산합니다. 이렇게 바꾼 뒤에는 argmax를 쓰는 변형(MAP answer)과 frontier가 같아졌고, Omni 곡선이 끝에서 꺾이던 현상이 사라졌습니다.

2. 확신도·중복 노드가 해로운 이유

확신도 노드는 거의 전부 난이도 신호로 학습됩니다: \(b_1 = 2.8\)–\(7.2\)로 크고, 정답 여부 효과 \(b_2\)는 \(-0.4\)–\(+0.4\)로 작고 부호도 셀마다 다릅니다. 응답 간 확신도 상관을 무시하고 독립 증거로 곱하기 때문에 사후확률이 과신하며, 보정 오차(ECE)가 9셀 중 7셀에서 M1보다 나빠집니다(Llama MATH 0.15 → 0.25). 중복 노드는 \(\rho = 0.33\)–\(0.99\)로 학습되고, GSM8K와 Llama MATH에서는 \(\rho \ge 0.9\)라 "같은 답의 반복은 대부분 복사"로 해석해 다수결 신호를 지웁니다. 실제 텍스트 유사도, hidden state, 무작위 통제군의 결과가 같으므로 reasoning path 중복 할인은 이 데이터에서 근거가 없습니다(v1과 같은 결론).

3. 적합된 파라미터 (M1)

사전분포 \(\mathrm{Beta}(a, b)\)의 한쪽 모수가 하한 근처(\(e^{-4} \approx 0.018\))에 붙은 셀이 많습니다. MATH·GSM8K는 \(b \approx 0.02\)(대부분 \(q \approx 1\)), Omni는 \(a \approx 0.02\)(대부분 \(q \approx 0\))입니다. 질문 난이도 분포가 Beta 하나로 표현하기 어려운 극단적 U자형이라는 뜻이고, 진단 1의 오설정과 같은 원인입니다. 다음 단계의 2성분 혼합 사전분포가 이것을 겨냥합니다.

08

결론과 다음 단계

  • 필요한 구조: 오답 CRP 군집과 생성모델 기반 VOI 정지. CRP를 빼면 frontier가 평균 3.9 pp 떨어지고, VOI를 확신도 threshold로 바꾸면 같은 정확도에 토큰이 크게 늘어납니다. 이 둘은 개수만 세는 ASC/ESC/ReASC에는 없는, 그래프 모델이 있어야 가능한 부분입니다.
  • 필요 없는 구조: 확신도 노드, reasoning 중복 노드, hidden state / embedding, 사후확률 argmax 답, \(\theta\)의 난이도 의존(평균 −0.1 pp).
  • 성능: threshold를 쓸어 얻는 곡선 전체로는 M1이 모든 baseline보다 왼쪽 위입니다. 하나의 운영점(SC16 − 1 pp, cross-fitting)에서는 같은 규칙으로 튜닝한 ASC보다 토큰을 11–51% 덜 쓰지만 정확도가 0.1–2.0 pp 낮고, Gemma·Qwen MATH에서는 그 차이가 유의합니다. "같은 정확도에서 우월"까지는 아직 아닙니다.
